# MEGA GAMES 2.0 — Android-проект

Это стартовая сборка интерфейса Android-приложения: игровое меню, каталог из 50 мини-игр, профиль-заготовка и экран сетевых комнат.

## Как собрать APK
1. Установите Android Studio (версия с поддержкой Android Gradle Plugin 8.7+).
2. Откройте папку `MEGA_GAMES_2` как проект.
3. Дождитесь загрузки Gradle и установите Android SDK 35.
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Важно: что уже работает
- Запускается Android-приложение с тёмным игровым оформлением.
- Есть каталог из 50 мини-игр и переходы между экранами.
- Можно выбрать ник.
- Есть интерфейс создания/ввода кода комнаты.

## Что ещё не реализовано в этой стартовой версии
- Реальные игровые механики всех 50 игр.
- Реальный обмен данными по Wi-Fi и через интернет.
- Регистрация, авторизация, список друзей и облачные приглашения.
- Синхронизация до 8 игроков.

Экран сетевой игры пока демонстрационный: код комнаты генерируется на устройстве и сам по себе не подключает другого игрока. Для настоящего мультиплеера нужен сервер комнат (например, Firebase Authentication + Cloud Firestore или собственный сервер), правила безопасности, синхронизация состояния игры и тестирование на нескольких устройствах. Мобильный интернет и Wi-Fi будут использовать один и тот же интернет-сервер; локальный режим можно дополнить обнаружением устройств в одной сети.
